## 0. 使用规则

1. **不得跳阶段**：未经用户确认，任何 Agent 不得越过未完成阶段提前开发。
2. **阶段门禁**：每阶段收尾必须满足四条 —— 构建通过、文档同步、ADR 更新（如有决策）、无死链。
3. **先定 R-01～R-05**：站点名、仓库名/`base`、语言前缀、尾斜杠策略、仓库可见性属于 P0（[风险清单](../../docs/risks-and-validation.md)），必须在写配置前定案，否则后面全是返工。
4. 阶段内允许调整实现细节，不允许调整**目标与验收标准**；要改就改本文并说明原因。

## 2. 阶段详述

### Phase 1 项目初始化与基础架构

- **目标**：得到一个能构建、能部署、目录结构清晰的空站点骨架。
- **前置条件**：R-01（站点名）、R-02（仓库名/`base`）、R-04（可见性）已定案。
- **交付物**：`package.json` 与 lockfile、`astro.config.mjs`（`site`/`base`/`i18n` 骨架）、`tsconfig.json`、`src/` 目录骨架、`.github/workflows/deploy.yml`（按官方形态）、一条 README 构建说明。
- **验收标准**：本地 `build` 成功；推送到 `main` 后 Pages 上线一个可访问页面；`base` 前缀下静态资源正常；构建时间 < 2 分钟。
- **依赖与风险**：依赖官方 Actions 版本（易变项，[参考](../../docs/references/github-pages-and-actions.md)）；lockfile 未入库会导致 Action 探测失败。

### Phase 2 设计系统与全局布局

- **目标**：把 [设计系统](../../docs/design/design-system.md) 落为可用的样式基础与全局框架。
- **前置条件**：Phase 1 完成；字体策略（TD-10）有初版结论。
- **交付物**：token 文件（浅/深两套）、reset、排版基线、Header/Footer/语言与主题切换壳、三态主题（含首屏无闪烁）、响应式断点。
- **验收标准**：切换三态刷新后保持；两种主题对比度实测达标；移动端无横向滚动；首屏无颜色闪烁。
- **依赖与风险**：字体体积（TD-10）；主题内联初始化脚本必须最小化。

### Phase 3 多语言系统

- **目标**：四语言路由、词典、语言切换、多语言元信息全部打通。
- **前置条件**：R-03（语言前缀）、R-05（尾斜杠）定案。
- **交付物**：`src/i18n/` 词典与语言配置、`[locale]` 路由展开、语言切换组件（区分站点级/内容级）、`<html lang>`/canonical/hreflang。
- **验收标准**：四种语言的站点级页面全部可构建；切换语言落在同一板块；无翻译内容不出现可点链接；无伪 hreflang。
- **依赖与风险**：`translationKey` 一致性（R-17）；`base` 与前缀组合正确（R-13）。

### Phase 4 内容模型与 Markdown 管理

- **目标**：内容集合、schema、派生索引可用，新增一篇内容只需新建文件。
- **前置条件**：Phase 3 完成；[数据模型](../../docs/architecture/data-models.md) 获确认。
- **交付物**：`src/content.config.ts`（五集合 + zod）、内容目录骨架、派生数据函数（分类/标签/年份/阅读时间/反向链接占位）、标签词表与归一规则、双向链接解析（TD-15）。
- **验收标准**：新建一篇 Markdown 后构建自动出现在列表；缺必填字段构建失败；悬空链接构建报错；分类/标签聚合正确计数。
- **依赖与风险**：schema 与文档必须同批更新（R-18）；"高级标签"语义（TD-16）未定前只做扁平标签。

### Phase 5 八大页面

- **目标**：八个页面全部可用，内容可读。
- **前置条件**：Phase 4 完成。
- **交付物**：Home、Blog 列表与详情、Projects 列表与详情、Knowledge 目录与条目、About、Gallery、Moments、Guestbook、404。
- **验收标准**：任意内容 ≤2 次点击可达；无 JS 时内容与导航可用；四语言站点级页面齐全；空数据有明确空状态。
- **依赖与风险**：图片体积（TD-12）；Moments 短视频策略未定前只支持图片与文字。

### Phase 6 搜索与阅读功能

- **目标**：搜索、TOC、阅读进度、阅读时间、分享、三种列表视图可用。
- **前置条件**：Phase 5 完成；TD-09（搜索方案）验证完成。
- **交付物**：构建后索引步骤、搜索 UI（浮层 + 独立页）、TOC、进度、时间、分享、三视图切换。
- **验收标准**：正文中段关键词可命中；只检索当前语言；`base` 下搜索可用；索引随构建自动更新；键盘可完成搜索全流程。
- **依赖与风险**：索引体积；构建顺序不可颠倒（[搜索](../../docs/integrations/search.md)）。

### Phase 7 交互功能

- **目标**：快捷键、灯箱、年度热力图、时间轴、本地音乐播放器可用。
- **前置条件**：Phase 5、6 完成；TD-11（音乐体积）有结论；TD-07（点赞）明确不做后不影响本阶段。
- **交付物**：`/` 与 `Esc` 快捷键、灯箱（键盘导航）、热力图（构建期统计）、时间轴、悬浮播放器。
- **验收标准**：键盘可完成灯箱与搜索操作；断网/无 JS 时这些功能整体隐藏而非半坏；播放器跨页不断播；热力图随新内容变化。
- **依赖与风险**：音乐体积与带宽（TD-11）；跨页播放需验证静态站下的可行方案。

### Phase 8 Waline 与第三方服务

- **目标**：评论与留言板上线；条件性功能按验证结果决定是否实现。
- **前置条件**：R-02/R-03 已定案（评论 path 冻结）；TD-08（服务端选型）完成；TD-06/TD-07 有结论。
- **交付物**：Waline 外部服务、客户端挂载、四语言 `lang` 映射、Guestbook 独立 path、失败降级、隐私说明。
- **验收标准**：Guestbook 与文章评论互不串扰；服务不可用时区块降级而页面正常；无合格方案时浏览量/点赞**完全不存在**（无按钮/字段/接口/占位）。
- **依赖与风险**：免费额度与停服风险；数据备份（TD-20）；密钥只在服务端。

### Phase 9 PWA

- **目标**：可安装、可离线、能及时更新。
- **前置条件**：Phase 2（主题色）、Phase 6（索引路径）完成。
- **交付物**：Manifest、图标集、Service Worker（网络优先 HTML）、版本化缓存、更新提示。
- **验收标准**：断网可打开首页与已读文章；重新发布后刷新能拿到新内容；评论接口不被缓存。
- **依赖与风险**：缓存与更新冲突（TD-13）；`base` 下的 `start_url`/`scope`（R-13）。

### Phase 10 SEO、隐私、安全

- **目标**：基础 SEO 与隐私安全要求全部落地。
- **前置条件**：Phase 5、3 完成。
- **交付物**：每页 title/description/canonical/hreflang/og、外链安全属性、图片 EXIF 清理流程、密钥与 `.env` 检查、依赖审计记录。
- **验收标准**：四语言页面元信息正确且无错配；[隐私清单](../../docs/security/privacy.md) 与 [安全清单](../../docs/security/security-baseline.md) 全部勾选；产物中无密钥字符串。
- **依赖与风险**：R-20（EXIF）；CSP 受 Pages 能力限制（待复核）。

### Phase 11 自动化部署

- **目标**：推送即发布，失败可诊断、可回滚。
- **前置条件**：Phase 1 起已有工作流；本阶段做加固。
- **交付物**：生产部署工作流（含搜索索引步骤）、构建缓存策略、发布后冒烟清单、回滚说明。
- **验收标准**：`main` 推送自动上线；构建失败有明确日志；回滚可在一个提交内完成；发布后四条路径冒烟通过。
- **依赖与风险**：10 分钟构建超时（R-21）；Actions 版本升级。

### Phase 12 最终验收

- **目标**：确认"可长期维护"这一真正目标达成。
- **前置条件**：Phase 1–11 全部完成。
- **交付物**：验收报告（写入 `plans/completed/`）、性能实测数据、文档一致性检查结果、债务台账复盘。
- **验收标准**：需求清单中所有 ✅ 项可用或已明确不实现；所有 `Needs Validation` 项有结论与证据；文档无死链；AGENTS.md 仍 ≤100 行且能引导新 Agent；无障碍与性能实测记录在案。
- **依赖与风险**：容易被压缩为"能打开就算完成"——必须按验收标准逐条核对，不得跳过。
