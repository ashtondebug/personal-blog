# 交互准则

> **用途**：定义动效、键盘、焦点、降级与空状态的统一规则。写任何交互脚本或浮层组件前必读。
> **状态**：Confirmed（快捷键 `/` 与 `Esc`、克制动效、响应式）+ Proposed（具体交互细节）
> **更新**：2026-11-26
> **相关**：[设计索引](./index.md) · [设计系统](./design-system.md) · [配色与主题](./color-and-theme.md) · [前端架构](../architecture/frontend-architecture.md) · [功能规格](../product/feature-specifications.md)

## 1. 交互清单

| 交互 | 触发 | 反馈 | 无 JS 时 |
| --- | --- | --- | --- |
| 打开搜索 | 点击图标 / `/` | 浮层淡入 + 焦点进入输入框 | 链接到 `/search/` 页面 |
| 关闭浮层 | `Esc` / 点击遮罩 / 关闭按钮 | 淡出，**焦点回到触发元素** | 不适用 |
| 主题切换 | 点击三态按钮 | 颜色 150–200ms 过渡 | 保持默认主题 |
| 列表视图切换 | 点击切换器 | 布局重排（不做逐项动画） | 固定默认视图 |
| 图片灯箱 | 点击缩略图 | 打开原图、左右翻页、`Esc` 关闭 | 直接打开原图链接 |
| TOC 跳转 | 点击目录项 | 平滑滚动 + 当前项高亮 | 锚点跳转 |
| 阅读进度 | 滚动 | 顶部细条变化 | 不显示 |
| 复制链接分享 | 点击 | 短暂"已复制"提示 | 显示可复制的规范链接 |
| 音乐播放 | 点击播放 | 播放/暂停状态与进度 | 不出现控件 |

## 2. 动效规则

- 时长与曲线使用 [设计系统 §5](./design-system.md) 的 token（120/200/320ms），**不得自创时长**。
- 只做"解释状态变化"的动效：浮层进出、展开收起、颜色过渡、滚动定位。
- 禁止：视差、自动轮播、无触发的循环动画、入场逐字/逐块动画、超过 400ms 的界面过渡。
- 必须响应 `prefers-reduced-motion: reduce`：关闭位移与缩放过渡，仅保留不超过 100ms 的透明度变化（或全部关闭）。
- 动画不得阻塞首屏渲染，也不得导致布局抖动（CLS）。

## 3. 键盘与焦点

| 规则 | 说明 |
| --- | --- |
| 全局快捷键 | `/` 打开搜索（焦点在输入框内时不劫持、输入法组合中不劫持）；`Esc` 关闭最上层浮层 |
| 浮层焦点 | 打开时焦点移入浮层，`Tab` 在浮层内循环，关闭后回到触发元素 |
| 可见焦点 | 所有可交互元素有 ≥2px 焦点环；禁止 `outline: none` 无替代 |
| 灯箱 | `←`/`→` 翻页，`Esc` 关闭，关闭后焦点回到对应缩略图 |
| 跳至正文 | 提供"跳到主要内容"跳过链接（skip link） |
| 语义 | 浮层/灯箱使用 dialog 语义（`role="dialog"` + `aria-modal`），标题与描述可被读屏获取 |

## 4. 响应式与移动端

- 断点与布局行为以 [设计系统 §4](./design-system.md) 为准。
- 触控目标 ≥ 44×44px；相邻可点元素间距 ≥ 8px。
- 移动端浮层使用全屏或底部抽屉，不用 hover 触发任何关键操作。
- 尊重安全区（`env(safe-area-inset-*)`），悬浮播放器不得遮挡底部导航。
- 不劫持横向滑动手势；不阻止页面缩放。

## 5. 加载、空状态与降级

| 场景 | 表现 |
| --- | --- |
| 搜索加载中 | 输入框下方轻量占位，不整屏 loading |
| 搜索无结果 | 明确说明 + 建议（换关键词、检查语言） |
| 评论服务不可用 | 区块内一行说明，页面其余内容正常 |
| 评论加载中 | 占位骨架，高度稳定避免跳动 |
| 图片加载失败 | 显示占位底色 + `alt` 文本，不出现裂图图标 |
| 搜索索引加载失败 | 提示可用的降级入口（浏览分类/标签） |
| JS 完全不可用 | 所有内容与导航可读；交互功能整体隐藏而非半坏 |

原则：**降级不是弹"出错了"，而是让当前页面仍然有用**。

## 6. 外部链接与分享

- 站外链接：`rel="noopener noreferrer"`，必要时 `target="_blank"` 并在可访问名称里提示"新窗口打开"。
- 分享只使用规范 URL 与纯链接，不加载第三方分享 SDK 或追踪像素。
- 复制链接失败时回退为可见可选的 URL 文本。

## 7. 验收

交互完成后逐条自查：键盘能完成主流程（打开搜索 → 输入 → 关闭；打开灯箱 → 翻页 → 关闭）；`prefers-reduced-motion` 下无位移动画；断网时页面仍可读；浅色/深色下焦点环均可见。
