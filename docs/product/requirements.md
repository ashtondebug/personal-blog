## 0. 状态标记约定

| 标记 | 含义 | Agent 可做什么 |
| --- | --- | --- |
| ✅ `Confirmed` | 用户明确确认 | 可以直接实现 |
| 🟡 `Proposed` | Agent 提议，尚未确认 | 只能作为方案候选，落地前必须先获确认 |
| 🔵 `Needs Validation` | 需要技术/政策验证才能确定 | 先验证、记录证据，再实现 |
| ⛔ `Deprecated` | 已废弃 | 不实现、不留接口、不留 UI、不留数据结构 |

**硬规则**：本文件中的 ✅ 项不得被 Agent 增删或改写语义；新增需求必须先由用户确认，再更新本文件。

## 1. 语言与本地化

| ID | 需求 | 状态 |
| --- | --- | --- |
| REQ-I18N-01 | 支持简体中文 `zh-CN`、繁体中文 `zh-TW`、English `en`、日本語 `ja` 四种语言 | ✅ |
| REQ-I18N-02 | 采用**独立语言文章策略**：一篇内容只属于一种语言 | ✅ |
| REQ-I18N-03 | 不强制翻译文章；某篇文章不存在其他语言版本时，不显示该语言入口 | ✅ |
| REQ-I18N-04 | 不自动生成机器翻译；不生成不存在的翻译链接（禁止 404 语言切换） | ✅ |
| REQ-I18N-05 | UI 与导航必须**完整国际化**（菜单、按钮、表单、空状态、分页、日期格式、Waline 语言） | ✅ |
| REQ-I18N-06 | 四语言元信息（`<html lang>`、`hreflang`/`canonical`、`og:locale`）随页面语言输出 | ✅ |
| REQ-I18N-07 | 默认语言与前缀策略（是否 `/zh-CN/` 前缀）未定 | 🔵 |
