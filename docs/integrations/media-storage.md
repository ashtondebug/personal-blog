# 媒体存储

> **用途**：图片、音乐、短视频的体积与存放策略。加任何媒体资源前必读，先算预算。
> **状态**：Confirmed（普通资源按体积决定是否入库、高清图与大型媒体可外置、音乐用本地资源）+ Needs Validation（外置方案、LFS、体积预算）

## 1. 先看硬限制

| 限制 | 数值 | 来源 |
| --- | --- | --- |
| 源仓库体积 | 建议 ≤ 1 GB | GitHub Pages 限制（官方核验 2026-11-26） |
| 发布站点体积 | ≤ 1 GB | 同上 |
| 软带宽 | 100 GB/月 | 同上 |
| 单文件大小 | 需复核 GitHub 对单文件的上限与警告阈值 | `Needs Validation` |

推论：**音频与高清图不能无限入库**。一首 5 MB 的 MP3，播放 200 次约 1 GB 流量——带宽比体积更早告急。

## 2. 三类资源的不同策略

| 类别 | 例子 | 存放 | 策略 |
| --- | --- | --- | --- |
| A. 小资源 | favicon、图标、小插图、示意图、代码截图 | 仓库 | 直接入库；单文件建议 ≤ 300 KB |
| B. 摄影作品（Gallery 主图） | 2–15 MB 原图 | **倾向外置**（对象存储/图床） | 仓库内只存压缩预览版；原图走外部 URL |
| C. 音乐 | MP3/M4A 音频 | 仓库（需求明确"本地资源"） | 严格控制数量与码率；见 §3 |
| D. 短视频（Moments） | 数 MB 到数十 MB | 倾向外置 | 不做站内转码，体积极小者才入库 |

## 3. 音乐体积预算（需求冲突点）

需求同时要求"音乐文件使用本地资源"和"GitHub Pages 托管"，二者在体积/带宽上冲突。可接受的做法：

1. 只保留**少量**曲目（Proposed：总音频 ≤ 50 MB）。
2. 使用较低码率（如 128 kbps）或统一转码。
3. 音频文件**不预加载**，仅在用户点击播放时请求。
4. 若超出预算 → 改外置存储，但这需要用户重新确认"本地资源"的要求（不得自行变更需求）。

预算表（Proposed，待校准）：

| 子目录 | 上限 | 说明 |
| --- | --- | --- |
| `public/music/` | 50 MB 总计 | 单曲 ≤ 8 MB |
| `src/assets/images/` | 20 MB 总计 | 主要是示意图与封面 |
| `public/images/gallery/` | 视外置方案而定 | 若外置，仓库内只留缩略图 |

## 4. 图片处理原则

- 现代格式优先（AVIF/WebP），保留回退；由构建器生成多尺寸。
- `<img>` 必须有 `width`/`height`（防布局跳动）与 `alt`（无障碍）。
- 非首屏图片 `loading="lazy"`；首屏主图不 lazy。
- **EXIF 中的 GPS 信息不得随图片入库**：拍摄地点可能指向住址（[隐私](../security/privacy.md)）。入库前剥离 EXIF。
- 外链图片需确认允许外链，并考虑对方服务失效时的降级（占位底色 + alt）。

## 5. 外置存储候选（均需验证）

| 方案 | 优点 | 风险 | 状态 |
| --- | --- | --- | --- |
| Cloudflare R2 + 自定义域 | 免费额度较大、无出站费用 | 需账号与配置；域名绑定 | Needs Validation |
| 图床（各类免费图床） | 零配置 | 稳定性与隐私不可控，可能随时关停 | 不推荐 |
| 对象存储（阿里云 OSS 等） | 国内访问快 | 可能产生费用（流量） | Needs Validation |
| 仓库 + Git LFS | 保留版本管理 | LFS 与 Pages 的兼容性/额度需验证；克隆成本上升 | Needs Validation |

选择标准：可长期免费或低成本、支持直链、不会因为我方流量被关停、图片可被 CDN 缓存。

## 6. 仓库卫生

- 大文件入库前先算：当前仓库体积 + 新增文件 / 1 GB。
- 二进制文件在 `.gitattributes` 中声明为 binary（已配置）。
- 误提交大文件后不要仅删除再提交（历史仍占体积），需评估是否重写历史（破坏性操作，需用户确认）。
- 定期检查仓库体积与发布站点体积，登记到 [技术债](../../plans/tech-debt.md) 的监控项。

## 7. 验收

- [ ] 新增媒体前确认所属类别与预算余额。
- [ ] 图片有宽高与 `alt`，无 EXIF GPS。
- [ ] 音频不预加载，点击才请求。
- [ ] 仓库与发布站点体积未超出 1 GB 建议值。
- [ ] 外链媒体在对方失效时有降级样式。
