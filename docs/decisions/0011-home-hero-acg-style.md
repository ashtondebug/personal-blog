# ADR-0011：首页二次元主视觉与"强调色"例外

> **用途**：说明首页为什么可以出现强调色、边界在哪。改首页视觉或想在内页加颜色前必读。
> **状态**：Confirmed（2026-11-26 用户明确要求并同意打破全站黑白灰）
> **更新**：2026-11-26
> **相关**：[决策索引](./index.md) · [设计原则](../design/design-principles.md) · [设计系统](../design/design-system.md) · [配色与主题](../design/color-and-theme.md) · [需求 §7](../product/requirements.md) · [Phase 9/10 报告](../../plans/completed/010-homepage-acg-style.md)

## 背景

项目已确认的视觉方向是**简约文艺 + 黑白灰**（REQ-VIS-01 / REQ-VIS-02），全站没有彩色主色。

2026-11-26 用户提出：**首页风格要符合二次元**，并确认"首页允许少量强调色（如青系/橙系）"，其余页面维持原方向；首页背景插画由作者最后提供。

这是一次**已确认需求的变更**，不是 Agent 自作主张，因此需要记录范围与边界，避免"首页开了口子，内页逐渐彩色化"。

## 决策

1. **范围仅限首页主视觉区**（`src/components/home/Hero.astro`）与首页章节标题的小标记。
2. **只引入一个强调色**：`--color-accent: #22d3ee`（青），配 `--color-accent-ink: #041018` 作其上的文字。**橙色备用但不落地**，避免颜色数量失控。
   - Hero 专属底色：`--color-hero-bg: #0e1116`、`--color-hero-text: #f2f4f7`、`--color-hero-muted: #a9b4c2`。
3. **表现手法**（不依赖插画也能成立）：粗描边 + 硬投影、漫画网点（radial-gradient）、斜向速度线、斜切标签、日文副标题、月牙与地平线图形。
4. **背景插画留槽位**：`src/config/home.ts` 的 `HERO_IMAGE` 为空时用 CSS 几何图形；作者放入 `public/images/` 后填一行即可替换，不会出现破图。
5. **内页零改动**：其余八个页面仍只用灰阶 token；`check-contrast` 会对新增 token 做校验，并单独列出"不随主题变化"的主视觉组合。

## 备选方案

| 方案 | 为什么没选 |
| --- | --- |
| 全站彩色化 | 违背已确认的黑白灰方向，也超出用户本次要求 |
| 保持纯黑白灰做"漫画线稿风" | 用户明确选择"允许少量强调色"，且二次元识别度需要一点色彩 |
| 引入第三方 UI 库/动画库做二次元 | 违背零框架与依赖最小化；纯 CSS 已能表达 |

## 影响

- 设计 token 从 7 个颜色角色扩展到 12 个；其中 5 个标注为"首页主视觉专用"，并写进 [设计系统](../design/design-system.md)。
- 对比度实测：主视觉文字 17.16:1、次要文字 9.00:1、强调色上文字 10.64:1、强调色对底色 10.46:1，全部 ≥ 4.5:1。
- 视觉一致性的风险从"会不会有颜色"变成"颜色会不会扩散"——防扩散手段是：token 命名带 `hero-` 前缀、只在 Hero 与首页标题使用、ADR 写明"扩到内页需新 ADR"。
- 背景插画未到位前，首页使用几何图形占位（不伪造作品），登记 TD-33。
