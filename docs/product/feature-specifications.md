# 功能规格

> **用途**：把 [需求清单](./requirements.md) 中的 ✅ 项拆解为可验收的行为规格。实现某个功能前读对应小节，不要读整篇。
> **状态**：Confirmed（行为来自用户需求）；标注 `[Proposed]` 的实现方式仍需确认。
> **更新**：2026-11-26
> **相关**：[需求清单](./requirements.md) · [信息架构](./information-architecture.md) · [交互准则](../design/interaction-guidelines.md) · [集成文档](../integrations/index.md)

每条包含：**行为** / **边界** / **依赖** / **验收要点**。技术实现只写约束，不写代码。

---

## 1. 全站搜索（REQ-READ-01、REQ-READ-08）

- 行为：关键词匹配标题、正文、分类、标签；结果按相关度排序，展示类型（文章/知识/项目/动态）与高亮片段。
- 边界：默认只检索**当前语言** 🔵；跨语言检索作为可选开关待验证；无结果时给明确空状态与建议。
- 依赖：构建期生成的静态索引；索引进构建产物，客户端按需加载。
- 验收：搜索一个只出现在正文中段的词能找到该文章；索引文件随构建自动更新，无需手写。

## 2. 文章目录 TOC（REQ-READ-02）

- 行为：从文章标题层级自动生成，滚动时高亮当前章节，点击平滑滚动。
- 边界：标题太少的短文章不显示 TOC；移动端折叠为抽屉。
- 依赖：Markdown/MDX 渲染出的 heading 数据（构建期可得）。
- 验收：h2/h3 全部出现在 TOC 中；锚点可被直接分享；不出现重复锚点冲突。

## 3. 阅读进度（REQ-READ-03）

- 行为：文章页顶部（或侧边）细进度条，随滚动变化；尊重 `prefers-reduced-motion`。
- 边界：仅内容详情页出现；评论/推荐区不计入进度。
- 依赖：客户端脚本读取滚动位置。
- 验收：首屏为 0，读到末尾约 100%，不抖动。

## 4. 阅读时间（REQ-READ-04）

- 行为：按正文字数估算，显示"约 N 分钟"。
- 边界：中/日文按字符数、英文按词数分别估算；图片不重罚；估算结果四舍五入到整分钟。
- 依赖：构建期计算，随 frontmatter 输出（不新增手工字段）。
- 验收：同一篇文章在列表与详情页显示的时间一致。

## 5. 社交分享（REQ-READ-05）

- 行为：详情页提供复制链接 + 若干常见平台分享。
- 边界：仅用纯链接分享（不引入第三方分享 SDK/追踪脚本）；无 JS 时至少保留可复制的规范链接。
- 依赖：canonical URL。
- 验收：分享出去的链接打开后是同一语言同一文章。

## 6. 主题模式（REQ-INT-01）

- 行为：浅色 / 深色 / 跟随系统三态；用户选择持久化；跟随系统时实时响应系统变化。
- 边界：首屏不得闪白/闪黑（需内联初始化脚本）；打印样式不受影响。
- 依赖：`prefers-color-scheme` 与本地存储。
- 验收：切换后刷新仍是选择值；系统模式切换时页面即时跟随；三态都有可见的当前状态。

## 7. 快捷键（REQ-INT-03）

- 行为：`/` 打开搜索并把焦点放入输入框；`Esc` 关闭当前浮层（搜索/灯箱/菜单）。
- 边界：焦点在输入框/评论框内时 `/` 不劫持；不与浏览器默认快捷键冲突；尊重输入法组合状态。
- 验收：键盘用户可完成"打开搜索 → 输入 → 关闭"全流程，无需鼠标。

## 8. 本地音乐悬浮播放器（REQ-INT-04、REQ-INT-09、REQ-INT-11）

- 行为：全站悬浮的小型播放器，可播放/暂停/切歌，显示曲名与进度，可最小化不挡内容。
- 边界：音乐文件为**本地资源**（仓库或构建产物）；跨页面跳转不断播（静态站需用持久化媒体或客户端路由保持）🔵；不自动播放带声音的媒体（浏览器策略与可用性）。
- 依赖：音频文件体积与仓库/Pages 容量限制 → 见 [媒体存储](../integrations/media-storage.md)。
- 验收：在文章页开始播放后切到 Gallery 仍继续播放；移动端不阻塞滚动；播放器可被键盘操作。

## 9. 年度热力图日历（REQ-INT-05）

- 行为：按日聚合发布量（文章/知识/动态合计），GitHub 风格年历；悬停显示当日内容。
- 边界：数据在构建期从内容集合统计，客户端零请求；时区按内容声明的日期（Asia/Shanghai 为默认）🔵。
- 验收：新增一篇当日文章并重新构建后，对应格子颜色变化。

## 10. 简约时间轴（REQ-INT-06）

- 行为：按年份分组的内容大事记（可复用于 About 或独立模块）。
- 边界：只展示标记为"里程碑"或全部的日期；移动端纵向单列。
- 验收：年份分组正确、倒序、可锚点直达某年。

## 11. 自由分类（REQ-CONTENT-09）

- 行为：分类可随内容自由新增，无需改代码；聚合页列出该分类下所有内容。
- 边界：分类名需归一化（避免 `Tech` 与 `tech` 并存）；空分类不生成页面。
- 验收：新建分类只需在 frontmatter 写新值，构建后自动出现聚合页与入口。

## 12. 高级标签系统（REQ-CONTENT-10）

- 行为：标签跨内容类型共享；支持标签聚合页、内容计数、关联推荐输入。
- 边界：**"高级"的具体语义未确认** 🔵（层级父子？别名同义？权重？）；确认前只实现扁平标签 + 别名归一，不提前造层级 UI。
- 验收：同一标签在 Blog 与 Knowledge 中都产生一致的聚合结果。

## 13. 三种列表视图（REQ-READ-06）

- 行为：列表 / 网格 / 杂志三视图，用户选择持久化。
- 边界：切换不改变 URL 与数据顺序；移动端默认单列且网格退化为两列。
- 验收：三种视图渲染的是同一数据集，条数与顺序一致。

## 14. Gallery 与灯箱（REQ-PAGE-06、REQ-CONTENT-07）

- 行为：摄影杂志式瀑布/错落布局；点击开灯箱（原图、上一张/下一张、`Esc` 关闭、键盘左右翻页）；作品显示元信息。
- 边界：高清图走外置存储或按体积决定是否入库 🔵；灯箱预加载相邻图但不预加载全部；`<img>` 必须有宽高与 `alt`。
- 验收：键盘能完整浏览图集；关闭灯箱后焦点回到触发缩略图。

## 15. Moments（REQ-PAGE-07、REQ-CONTENT-08）

- 行为：时间倒序流；支持纯文字、图片、短视频；每条有独立详情链接（可分享）。
- 边界：短视频需考虑体积与格式（转码/压缩外置）🔵；无 JS 时列表仍可阅读；详情页含前后条导航。
- 验收：任意一条动态都可被单独链接打开并展示完整内容。

## 16. Guestbook 与 Waline（REQ-PAGE-08、REQ-DATA-01、REQ-DATA-02）

- 行为：独立留言板页面，Waline 以**固定独立 path** 标识，与文章评论互不混淆。
- 边界：文章评论 path 必须与文章稳定 URL 绑定；URL 变更会导致评论"丢失"（实为指向新 path），需迁移策略；Waline 服务端为外部独立服务。
- 验收：在 Guestbook 留言不会出现在任何文章评论区，反之亦然。

## 17. 浏览量（REQ-DATA-03、REQ-DATA-04）

- 行为：**仅当**存在满足条件的免费第三方方案时，在内容页展示浏览数。
- 边界：不得伪造、不得用占位数字、不得为凑效果引入付费或强追踪服务。若验证失败 → 全站不展示，也不保留 UI 占位。
- 验收：数值来自真实接口；不满足条件时仓库中不存在相关组件与字段。

## 18. 点赞（REQ-DATA-05）

- 行为：默认**不实现**。只有找到真正免费且满足要求的服务时才启用。
- 边界：若最终弃用，仓库中不得存在按钮、UI、接口、数据结构或占位注释。
- 验收：全仓搜索无点赞相关残留（除非已启用并有 ADR 记录）。

## 19. PWA（REQ-INT-07、REQ-INT-10）

- 行为：可安装、离线打开已访问过的页面、有图标与主题色。
- 边界：必须 HTTPS（GitHub Pages 默认满足）；内容更新后不能让用户长期看到旧版本（缓存策略需明确）🔵；不得缓存评论/搜索等强时效内容。
- 验收：断网后能打开首页与一篇已读文章；重新部署后刷新能拿到新内容。

## 20. 双向链接与关联推荐（REQ-CONTENT-05、REQ-CONTENT-11）

- 行为：Knowledge 条目内引用另一条目，双方都显示关联；详情页底部给"相关条目/相关文章"。
- 边界：链接解析在构建期完成；悬空链接（目标不存在）必须构建期报错或显式降级，不能静默产生死链。
- 验收：新增一条引用后重新构建，反向链接自动出现在目标条目页。

## 21. 项目详情页（REQ-PAGE-03、REQ-CONTENT-06）

- 行为：统一模板承载：介绍、技术栈、架构、开发过程、截图、仓库链接。
- 边界：字段可选但结构固定；仓库链接带 `rel="noopener noreferrer"`；无封面时有明确占位样式而非裂图。
- 验收：新增项目只需新增一份内容文件，字段缺失不导致构建失败（除非必填校验明确要求）。
