# 全站搜索

> **用途**：搜索能力的实现约束：索引怎么建、多语言怎么分、`base` 怎么处理、如何与 `/` 快捷键衔接。做搜索前必读。
> **状态**：Confirmed（需要全站增强搜索）+ Proposed（实现方案）+ Needs Validation（索引方案与体积）
> **更新**：2026-11-26
> **相关**：[集成索引](./index.md) · [功能规格 §1](../product/feature-specifications.md) · [前端架构](../architecture/frontend-architecture.md) · [交互准则 §3](../design/interaction-guidelines.md) · [部署架构](../architecture/deployment-architecture.md)

## 1. 需求边界

- 检索范围：标题、正文、分类、标签（[REQ-READ-01](../product/requirements.md)）。
- 结果需展示内容类型（文章/知识/项目/动态/图集）与命中片段。
- 静态站无服务端 → 必须是**构建期建索引 + 浏览器查询**（[ADR-0007](../decisions/0007-static-dynamic-service-boundary.md)）。
- 默认只检索**当前语言**（更符合"独立语言文章"策略；跨语言检索未确认）。

## 2. 方案候选

| 方案 | 机制 | 优点 | 代价 | 状态 |
| --- | --- | --- | --- | --- |
| **Pagefind 1.6.0** | 构建完成后扫描输出 HTML 生成分片索引，客户端按需拉取 | 与框架无关、按语言分目录可分别建索引、无需手写索引结构、查询在浏览器完成 | 多一个构建步骤；索引构建需在 `astro build` 之后；产物体积需实测 | **第一候选**（Needs Validation） |
| 自建 JSON 索引 | 构建期输出每篇正文的 JSON，客户端用简单匹配 | 完全可控、无额外依赖 | 需要自己处理分词、相关度、体积；索引体积易失控 | 备选 |
| 外部搜索服务（Algolia 等） | 上传索引到第三方 | 体验最好 | 不免费/额度限制/多一个账号与隐私面 | 不推荐 |
| 浏览器内置 `Ctrl+F` | 不实现 | 零成本 | 不满足"全站增强搜索"需求 | 排除 |

Pagefind 的版本事实来自 npm registry 官方元数据（核验 2026-11-26），其稳定性与 `base` 支持需按官方文档复核。

## 3. 构建顺序（不可颠倒）

1. `astro build` → 产物目录。
2. 索引器扫描产物，生成索引目录（Pagefind 默认在产物内生成 `pagefind/`）。
3. 上传产物并发布。

若顺序颠倒，索引会把"上一次构建"的内容写进去；若索引目录被部署流程忽略，搜索会静默失效 → 必须在发布后验证一次搜索。

## 4. 多语言索引

两种可选（`Needs Validation`）：

| 方案 | 说明 | 取舍 |
| --- | --- | --- |
| 按语言分索引 | 每种语言一个索引子目录，页面只加载自己语言的索引 | 体积最小、结果最准；构建步骤需按语言区分 |
| 单索引 + 语言字段 | 只建一份，查询时过滤 | 简单，但每个页面都要下载全部语言的数据 |

倾向"按语言分索引"：与目录结构天然对应，且避免英文页面下载中文索引。

## 5. `base` 前缀

索引资源与 UI 资源都位于产物内的固定路径，配置 `base` 后必须能从 `/<repo>/pagefind/...` 访问。因此：

- 加载索引与 UI 的路径必须由构建配置生成，禁止手写 `/pagefind/`。
- 发布后需确认：请求返回 200，而不是 404 或被 Pages 的 404 页顶替。

## 6. 交互衔接

- `/` 打开搜索浮层（焦点进入输入框），`Esc` 关闭（[交互准则](../design/interaction-guidelines.md)）。
- 浮层与独立 `/search/` 页共用同一查询逻辑；无 JS 时至少有可用的搜索页或明确降级入口。
- 输入防抖；查询不阻塞输入；无结果给明确空状态与建议。
- 结果按相关度排序，展示类型与高亮片段；点击进入对应语言的内容页。

## 7. 体积与性能

- 单语言索引目标 ≤ 500 KB（Proposed，需实测）；超出则调整索引内容（只索引正文、排除代码块等）。
- 索引按需加载：未打开搜索时不下载。
- 接受首选题能接受的构建耗时增加（视频/图片无关，主要看内容量）。

## 8. 验收标准

- [ ] 只在正文中段出现的词能命中该文章，并高亮片段。
- [ ] 搜索结果只包含当前语言的内容。
- [ ] 新增/删除一篇内容并重新构建后，索引随之变化（无人手工维护文件）。
- [ ] `base` 前缀下搜索可用（无 404）。
- [ ] 键盘可完成"打开 → 输入 → 选择结果"全流程。
- [ ] 索引资源未加载时页面不报错，搜索入口给出降级提示。
