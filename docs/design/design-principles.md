## 1. 不可动摇的前提（用户确认）

1. **简约文艺**：留白优先，装饰克制，情绪来自排版与图片，而不是来自图形元素。
2. **黑白灰**：全站无彩色主色。层次靠字号、字重、灰度、间距与线条。
3. **杂志编辑式排版**：标题有编辑感（字号跨度大、字距讲究），正文可长读。
4. **三种主题模式**：浅色、深色、跟随系统。
5. **响应式、桌面与移动统一架构**：同一套页面结构，不同的排布，不做两套站。
6. **丰富但克制的动效**：动效解释状态变化，不表演。

## 2. 推导出的设计原则

### P1 内容优先于容器

文章、图片、时间线是主角。卡片、描边、阴影只在确实需要分组时出现；能用留白分组就不用边框 `[Proposed]`。

### P2 一种强调手段

同一屏内最多用**一种**强调方式（字重、下划线、灰度反转）。禁止同时用颜色 + 阴影 + 边框 + 大字号去抢注意力。

### P3 灰度不是单调

黑白灰的层次来自至少五级灰阶（背景/次级背景/分隔线/次要文字/主文字）+ 两档字重。层次不足时先加灰阶与间距，**不要**引入彩色。

### P4 排版即品牌

标题与正文的对比（尺寸、字体族、字距）承担识别度。标题可大但要可预测；正文行长 60–75 字符（中文 30–38 字/行）`[Proposed]`。

### P5 动效服务于定位

允许：主题切换的柔和过渡、浮层进出、图片灯箱、滚动进度、链接下划线。禁止：视差滚动、自动轮播打扰、无触发的循环动画、超过 400ms 的界面过渡 `[Proposed]`。

### P6 可读性优先于创意

任何视觉手法若使正文对比度低于 WCAG AA，或使移动端横向溢出，一律让位。

### P7 诚实呈现

不展示没验证过的数据（浏览量、点赞）、不生成不存在的语言入口、不用占位图伪装成作品。这条是产品级原则，不只是设计原则。

### P8 例外必须是显式的

唯一允许的视觉例外是**首页二次元主视觉 + 一个强调色**（[ADR-0011](../decisions/0011-home-hero-acg-style.md)），因为它由作者明确要求并写入了决策记录。例外不靠口口相传：token 用 `hero-` 前缀命名、校验脚本单独成组、想扩到内页必须先改 ADR。

## 3. 反模式（禁止）

| 反模式 | 为什么禁止 |
| --- | --- |
| 彩色渐变主视觉、玻璃拟态、霓虹光效 | 违反"简约文艺/黑白灰" |
| 大量卡片 + 阴影堆叠的"仪表盘感" | 与杂志编辑式排版冲突 |
| 每屏都出现的动画干扰（旋转、呼吸、打字机） | 违反"克制" |
| 用 emoji 代替图标承担导航 | 与编辑式排版气质冲突，且跨语言渲染不一致 |
| 深色模式简单反相（纯黑 `#000` + 纯白文字） | 刺眼、丢失层次 |
| 中英混排不做标点/间距处理 | 中文排版的核心细节，见 [排版](./typography.md) |

## 4. 与实现的关系

本文件只约束取舍，不定义数值。所有可测量值（字号、间距、灰阶、时长、断点）集中在 [设计系统](./design-system.md) 的 token 表；改数值改那张表，不要散落在组件里。
