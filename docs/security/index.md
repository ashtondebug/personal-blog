> **更新**：2026-11-26

## 2. 硬规则（来自需求，不可协商）

1. 不公开真实姓名、学校、班级、住址及私人联系方式。
2. **不编造个人资料**——没有的信息就留空或让作者填写。
3. 前端不暴露任何 API 密钥、数据库凭据、服务端令牌。
4. 减少不必要的第三方请求与追踪；使用 HTTPS；外链加安全属性。
5. 定期检查依赖项。
6. 统计与点赞等能力，**没有合格的免费方案就不做**，不得用假数据替代。

## 3. 什么时候必须读本板块

- 要往页面里加任何第三方脚本（评论、统计、字体、图标 CDN）。
- 要发布包含人像、地点、住址线索的图片。
- 要新增环境变量或构建期凭证。
- 要更换评论服务或其数据库。

## 4. 变更要求

涉及隐私或安全的实现变更，必须同批更新本板块对应文档与 [风险清单](../risks-and-validation.md)；涉及外部服务新增时追加 ADR。
