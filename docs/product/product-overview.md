## 1. 一句话定位

一个**简约文艺风格的多语言个人门户型博客**：以文字与摄影为主，静态生成、可长期维护、可被 AI Agent 持续开发。

## 2. 内容定位

四个核心内容方向（用户确认，长期不变）：

| 方向 | 英文标识 | 内容 |
| --- | --- | --- |
| 技术 | `Tech` | 编程、开源项目、AI、嵌入式开发 |
| 生活 | `Life` | 日常记录、学习经历、摄影、旅行 |
| 知识 | `Knowledge` | 技术教程、学习笔记、概念解释 |
| 思考 | `Thought` | 个人观点、随笔、技术与生活思考 |

四个方向是**分类轴**，不是独立站点。Blog 与 Knowledge 共用这套分类；Projects、Gallery、Moments、Guestbook 各自独立，但可被分类与标签引用。

## 3. 八大页面

| 页面 | 定位 | 主要形态 |
| --- | --- | --- |
| Home | 极简个人主页 | 静态、首屏即形象 |
| Blog | 正式文章 | 列表（列表/网格/杂志三视图）+ 杂志式文章页 |
| Projects | 独立项目展示 | 列表 + 每项目独立详情页 |
| Knowledge | 知识管理 | 层级目录 + 双向链接 + 全文搜索 |
| About | 简洁个人介绍 | 静态长文、无编造个人信息 |
| Gallery | 摄影作品 | 摄影杂志式布局 + 灯箱 + 作品元信息 |
| Moments | 短动态 | 时间倒序、文字/图片/短视频、独立详情链接 |
| Guestbook | 独立留言板 | 独立 Waline 页面标识 |

页面职责与依赖关系见 [信息架构](./information-architecture.md)。

## 4. 目标与成功标准

**使用者视角的成功**：读者能在 3 秒内理解这是谁的站点、在 2 次点击内到达任何一篇内容；中/繁/英/日四种语言的界面完整可用，不出现"假装有翻译"的死链接。

**维护者视角的成功**（本项目真正的验收重点）：

1. 新增一篇中文文章 = 只新建一个 Markdown 文件 + 提交，不需要改任何组件或路由代码。
2. 新增一种语言不需要重写页面组件（页面用 `[...locale]` 参数化，文案集中在词典）。
3. 一个**全新的 Agent**、没有本次对话记录，也能从 [AGENTS.md](../../AGENTS.md) 出发在 5 分钟内定位：需求在哪、架构在哪、下一步做什么、哪些事不能自己决定。
4. 站点完全静态：GitHub Pages 上只有 HTML/CSS/JS/媒体文件，无服务端进程。

## 5. 非目标

以下是**明确不做**或**尚未决定**的方向，Agent 不得自行引入：

- 不做内容管理后台（无 CMS、无在线编辑器）`[Proposed]`。
- 不做用户注册、登录、个人中心（Waline 评论身份除外）。
- 不做服务端渲染、API 路由、数据库（除 Waline 自有后端外）。
- 不默认引入 React / Vue / Svelte 等前端框架（见 [ADR-0006](../decisions/0006-no-default-ui-framework.md)）。
- 不做机器翻译、不自动生成不存在的语言版本（用户明确禁止）。
- 不在前台暴露任何 API 密钥或数据库凭据。
- 第一阶段不写任何业务代码（本阶段目标是知识体系，见 [路线图](../../plans/active/000-initial-implementation-roadmap.md)）。

## 6. 站点命名

用户确认方向为**空间概念型命名**（如星、轨道、坐标、气层之类意象），**具体名称未定**。

- 状态：`Needs Validation`（需要用户决策，Agent 不得擅自定名并写死到代码里）。
- 影响面：`site` 配置、站点标题、logo 文案、OG/meta、PWA `name`/`short_name`、仓库名与 GitHub Pages 路径。
- 规避方式：内容与代码中一律通过配置项/词典键引用站点名，禁止硬编码字符串。

## 7. 隐私前提（产品级约束）

站点面向公开访问，**不得出现真实姓名、学校、班级、住址、私人联系方式**，也不得由 Agent 编造个人资料。详见 [隐私规范](../security/privacy.md)。

## 8. 本阶段边界

本项目当前处于 **Phase 0：项目知识体系建立**。已完成：需求固化、架构地图、技术决策记录、开发路线图、文档一致性工具。未开始：任何页面、组件、样式、业务脚本。
